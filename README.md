# রক্তবন্ধু

একটি সহজ ও সুন্দর বাংলা ওয়েবসাইট, যেখানে রক্তের গ্রুপ, Rh ফ্যাক্টর এবং রক্তদানের সামঞ্জস্য সম্পর্কে প্রাথমিক ধারণা দেওয়া হয়েছে।

## প্রজেক্টের লক্ষ্য

- রক্তের গ্রুপ সম্পর্কে সচেতনতা বাড়ানো
- সহজ ভাষায় তথ্য উপস্থাপন
- মোবাইল-ফ্রেন্ডলি ও সুন্দর UI তৈরি
- রক্তদানের সামঞ্জস্য যাচাইয়ের জন্য ব্যবহারবান্ধব ইন্টারফেস দেওয়া

## ফিচার

- ৮টি রক্তের গ্রুপের লিস্ট
- A/B/O/AB ও Rh (+/-) ব্যাখ্যা
- রক্তের গ্রুপ সামঞ্জস্য চেকার
- মোবাইল-রেসপন্সিভ ডিজাইন
- পরিষ্কার বাংলা কনটেন্ট

## প্রযুক্তি

- HTML
- CSS
- JavaScript

## লোকালভাবে চালানো

1. এই ফোল্ডারটি খোলা রাখুন
2. `index.html` ফাইলটি ব্রাউজারে open করুন
3. অথবা লোকাল সার্ভার চালিয়ে দেখুন:

```bash
python -m http.server 8000
```

তারপর ব্রাউজারে `http://localhost:8000` খুলুন।

## ব্যবহার

- রক্তের গ্রুপগুলো দেখুন
- "গ্রুপ মিলিয়ে দেখুন" সেকশনে আপনার গ্রুপ বাছাই করুন
- সাধারণ রক্তদানের সামঞ্জস্য সম্পর্কে জানুন
- Rh ফ্যাক্টর ও নিরাপদ রক্তদানের ব্যাপারে তথ্য পড়ুন

## মনে রাখবেন

এই ওয়েবসাইটটি শুধুমাত্র শিক্ষামূলক তথ্যের জন্য। প্রকৃত চিকিৎসা সিদ্ধান্তের জন্য ডাক্তারের পরামর্শ নেওয়া উচিত।
