# রক্তবন্ধু

একটি সহজ ও সুন্দর বাংলা ওয়েবসাইট, যেখানে রক্তের গ্রুপ, Rh ফ্যাক্টর এবং রক্তদানের সামঞ্জস্য সম্পর্কে প্রাথমিক ধারণা দেওয়া হয়েছে।

## প্রজেক্টের লক্ষ্য

- রক্তের গ্রুপ সম্পর্কে সচেতনতা বাড়ানো
- সহজ ভাষায় তথ্য উপস্থাপন
- মোবাইল-ফ্রেন্ডলি ও সুন্দর UI তৈরি
- রক্তদানের সামঞ্জস্য যাচাইয়ের জন্য ব্যবহারবান্ধব ইন্টারফেস দেওয়া

## ফিচার

- ৮টি রক্তের গ্রুপের লিস্ট
- A/B/O/AB ও Rh (+/-) ব্যাখ্যা
- রক্তের গ্রুপ সামঞ্জস্য চেকার
- browser-এ দাতা নিবন্ধন, গ্রুপ ফিল্টার এবং ফোনে যোগাযোগ
- রক্তের অনুরোধ তৈরি, জরুরিতা/প্রয়োজনের সময়সহ তালিকা, ও request মুছে ফেলা
- একই browser-এ নিবন্ধিত সামঞ্জস্যপূর্ণ দাতার সংখ্যা দেখানো
- দাতা ও অনুরোধের তথ্য browser local storage-এ সংরক্ষণ
- মোবাইল-রেসপন্সিভ ডিজাইন
- পরিষ্কার বাংলা কনটেন্ট

দাতা নিবন্ধন ও রক্তের অনুরোধের তথ্য শুধু যে browser-এ যোগ করা হয়েছে সেই browser-এর local storage-এ থাকে। এই static demo-তে server, account system, cross-device sync, বা অনলাইন notification নেই। বাস্তব রোগী-সেবা চালুর আগে নিরাপদ backend, পরিচয়/সম্মতি ব্যবস্থাপনা এবং হাসপাতাল-নিশ্চিত রক্তের সামঞ্জস্য পরীক্ষা যোগ করতে হবে।

## প্রযুক্তি

- HTML
- CSS
- JavaScript

## লোকালভাবে চালানো

1. এই ফোল্ডারটি খোলা রাখুন
2. `index.html` ফাইলটি ব্রাউজারে open করুন
3. অথবা লোকাল সার্ভার চালিয়ে দেখুন:

```bash
python -m http.server 8000
```

তারপর ব্রাউজারে `http://localhost:8000` খুলুন।

## ব্যবহার

- রক্তের গ্রুপগুলো দেখুন
- "গ্রুপ মিলিয়ে দেখুন" সেকশনে আপনার গ্রুপ বাছাই করুন
- "দাতা / অনুরোধ" সেকশনে তথ্য যোগ করে সেই browser-এ সংরক্ষণ দেখুন
- সাধারণ রক্তদানের সামঞ্জস্য সম্পর্কে জানুন
- Rh ফ্যাক্টর ও নিরাপদ রক্তদানের ব্যাপারে তথ্য পড়ুন
