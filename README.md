একটি সুন্দর ও ব্যবহারবান্ধব বাংলা ওয়েবসাইট, যেখানে রক্তের গ্রুপ, Rh ফ্যাক্টর, রক্তদানের সামঞ্জস্য এবং দাতা-গ্রহীতা সম্পর্কিত প্রাথমিক তথ্য সহজভাবে উপস্থাপন করা হয়েছে।

## প্রকল্পের উদ্দেশ্য

- রক্তদানের গুরুত্ব সম্পর্কে মানুষকে সচেতন করা
- রক্তের গ্রুপ ও Rh ফ্যাক্টর সম্পর্কে সহজ ভাষায় ধারণা দেওয়া
- রক্তের সামঞ্জস্য যাচাইয়ের জন্য ব্যবহারবান্ধব ইন্টারফেস তৈরি করা
- দাতা ও রক্তের অনুরোধের তথ্য সহজে সংরক্ষণ ও দেখার ব্যবস্থা করা

## ফিচার তালিকা

- ৮টি মূল রক্তের গ্রুপের তালিকা
- ABO ও Rh (+/-) ফ্যাক্টর ব্যাখ্যা
- রক্তের গ্রুপ সামঞ্জস্য চেকার
- browser-এ দাতা নিবন্ধন ও তথ্য সংরক্ষণ
- রক্তের অনুরোধ পোস্ট করা ও জরুরীতা অনুযায়ী তালিকা দেখা
- গ্রুপ অনুযায়ী দাতা ফিল্টার করা
- একই browser-এ ডেটা local storage তে রাখা
- মোবাইল-ফ্রেন্ডলি সুন্দর UI
- বাংলা ভাষায় পরিষ্কার, সহজবোধ্য কনটেন্ট

## ডেমো ও ব্যবহার

এই প্রজেক্টটি একটি static demo হিসেবে তৈরি করা হয়েছে। এখানে ব্যবহারকারীরা:

- রক্তের গ্রুপ সম্পর্কে জানতে পারবে
- "গ্রুপ মিলিয়ে দেখুন" সেকশনে সামঞ্জস্য পরীক্ষা করতে পারবে
- দাতা হিসেবে তথ্য যোগ করে browser-এ সংরক্ষণ করতে পারবে
- রক্তের অনুরোধ পোস্ট করতে পারবে
- দাতার তালিকা ও ফিল্টার করতে পারবে

> উল্লেখ্য: এই অ্যাপটি শুধুমাত্র front-end demo; এখানে সত্যিকারের backend, authentication, database বা real-time sync নেই। বাস্তব রক্তদান ব্যবস্থার জন্য নিরাপদ backend, ডেটা যাচাই, সম্মতি ব্যবস্থা ও hospital-level validation প্রয়োজন।

## লোকাল পরিবেশে চালানো

### ১) ফাইল খোলা

কেবল `index.html` ফাইলটি ব্রাউজারে open করলেই কাজ করবে।

### ২) লোকাল server চালানো

```bash
python -m http.server 8000
```

তারপর ব্রাউজারে এই URL-এ যান:

```text
http://localhost:8000
```

## কিভাবে ব্যবহার করবেন

1. ব্রাউজার খুলুন
2. "গ্রুপ মিলিয়ে দেখুন" সেকশনে আপনার রক্তের গ্রুপ নির্বাচন করুন
3. "দাতা / অনুরোধ" সেকশনে তথ্য পূরণ করুন
4. browser local storage-এ সংরক্ষিত ডেটা দেখতে পারবেন
5. রক্তের গ্রুপ ও সামঞ্জস্য সম্পর্কে জ্ঞান নিতে পারবেন
